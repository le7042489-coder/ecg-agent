signal_quality_tool：

前提确认

- ECGAssess 核心算法 129 行,依赖 scipy.signal + py-ecg-detectors + neurokit2(后两个你已有或轻量)
- 唯一新增依赖:py-ecg-detectors(pip install py-ecg-detectors)
- 源码全局变量写死 sampling_frequency=500,window_length=100 — 需参数化
- SNR 算法里 pxx_den[(signal_freq_band[0]*10):(signal_freq_band[1]*10)] 是按 periodogram 频率分辨率 0.1 Hz(= 1/10s)硬编码的索引 — 信号不足 10s 时索引会偏,需按实际 f 数组查找
- 无 license 文件,需注意引用

步骤

1. Vendor ECGAssess 核心 → src/medrax/tools/signal_quality.py

从 AlgorithmsV5.py 提取三个判据函数,改造为:
- fs 全参数化(滤波器、窗长、periodogram 索引均按实际 fs 计算)
- 输入从 data[lead](GUI 的全局数组)改为 (signal_8ch: np.ndarray, fs: int),8 通道 × N 采样点
- 去掉 GUI 残留(bigO/time/unicode 符号)
- 输出结构化 dict,不再是 unicode 矩阵

2. 构建 ECGSignalQualityTool(BaseTool)

同一文件内,封装为 LangChain BaseTool:
- _run(ecg_path):加载 .mat → 提取 8 物理通道(I, II, V1–V6,跳过导出的 III/aVR/aVL/aVF)→ 读 curr_sample_rate
- 主输出(ECGAssess):逐导 acceptable/unacceptable + 失败判据(stationarity/heart_rate/snr)
- 辅助输出(NeuroKit):逐导 nk.ecg_quality() 连续分(0–1,averageQRS 法)
- 汇总:整体 overall_quality(all_acceptable / partial / all_unacceptable)+ suspect_electrodes 映射(哪些电极可能需要检查)
